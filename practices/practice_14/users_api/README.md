# Users - a Flutter REST client

A multi-screen users directory for Android: read a real REST API, survive a restart and an offline launch, and install a signed release.

| ![list](docs/list.png) | ![offline](docs/offline.png) |
|---|---|
| Users list over the network | Saved data when the API is unreachable |

## Run it

```bash
flutter pub get
flutter run                                      # defaults, no defines
flutter run --dart-define=USE_FAKES=true         # no network needed
flutter run --dart-define-from-file=env/local.json
flutter build apk --release --dart-define-from-file=env/prod.json
```

Release APK (arm64): [Releases](https://github.com/Dauserr/flutter-2026-serikbayev-daulet/releases/tag/v1.0.1) - v1.0.1, install on any Android phone.

## Architecture (five lines)

- `features/<name>/` - screen, ChangeNotifier, repository, per feature
- `core/api/` - ApiClient: `Uri.https`, 10 s timeout, sealed `ApiException`
- repositories behind interfaces; fakes for tests and `USE_FAKES`
- storage: `shared_preferences` for settings, secure storage for a token, a file cache for users
- `flutter test`: 10 tests - models, error mapping, one widget test

## Release

```bash
flutter build apk --release --split-per-abi --obfuscate --split-debug-info=build/symbols \
  --dart-define-from-file=env/prod.json \
  --android-project-arg=force-version-code-ignoring-abi=true

flutter build appbundle --release --dart-define-from-file=env/prod.json
```

The split build produces three APKs. `app-arm64-v8a-release.apk` is archived with `build/symbols/` in `releases/1.0.1+2/` (artifacts are kept outside git). `--android-project-arg=force-version-code-ignoring-abi=true` keeps the store build number at `2` in About instead of Flutter's ABI-suffixed number.

## Pre-release checklist

- [x] **Identity** — `applicationId` and namespace are `kz.serikbayev.users`; MainActivity is in the same package.
- [x] **Version** — `pubspec.yaml` is `1.0.1+2`; Gradle uses `flutter.versionCode` and `flutter.versionName`.
- [x] **Signing** — release APK signed with `upload` key; `keytool -printcert` output is in `NOTES.md`.
- [x] **Secrets** — `.gitignore` covers `*.jks`, `*.keystore`, `android/key.properties`; key and properties are not in git.
- [x] **Environment** — `lib/core/env.dart` is the only file containing `fromEnvironment`.
- [x] **Fakes** — `USE_FAKES=true` selects `FakeUserRepository`; no network call.
- [x] **Environment files** — `env/local.json`, `env/prod.json`, and the four run/build commands are listed above.
- [x] **About** — version, build number, mode, `Env.name`, `Env.host`, and licence page are in `AboutScreen`.
- [x] **Debug host switch** — the API-host tile exists only behind `if (kDebugMode)` in Settings.
- [x] **Icon** — custom 1024 icon and adaptive foreground generated by `flutter_launcher_icons`.
- [x] **Splash** — splash and Android 12 splash generated by `flutter_native_splash`.
- [x] **Name and network** — Android label and iOS display name are `Users`; `INTERNET` is declared in the main manifest.
- [x] **Release artifact** — arm64 release APK and symbols archived in `releases/1.0.1+2`; appbundle built.
- [x] **Real phone and GitHub Release** — installed from the file on a physical Android phone (PLG110), tested over mobile data, About screenshot captured; GitHub Release [v1.0.1](https://github.com/Dauserr/flutter-2026-serikbayev-daulet/releases/tag/v1.0.1) contains the arm64 APK, and `screenshot_release_page.png` shows the release page.
